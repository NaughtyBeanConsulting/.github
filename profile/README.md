# Naughty Bean Consulting

<p align="center">
	<strong>Building practical software for operations, commerce, and security.</strong>
</p>

Naughty Bean Consulting is a South African product and engineering studio focused on shipping opinionated, working software instead of vague platform promises.

We build tools for real operating environments: retail ordering, self-hosted security operations, documentation systems, branded web experiences, and lightweight support flows that connect directly to production needs.

## What we build

### Scutiva

Scutiva is an open-source, self-hosted security operations portal for Linux hosts and application codebases.

- Agentless server onboarding over SSH
- SBOM generation and package vulnerability correlation
- Linux posture and hardening checks
- Findings review, job tracking, and operator workflows
- Open-source security tooling assembled into a usable product surface

Core technologies:

- Django
- PostgreSQL
- Paramiko
- HTMX
- Alpine.js
- Tailwind CSS
- WhiteNoise
- Lynis
- Syft
- Grype
- Trivy

Project: https://github.com/NaughtyBeanConsulting/Scutiva

### ClickCollect.coffee

ClickCollect.coffee is a multi-tenant SaaS platform for coffee shops and branded food retail storefronts.

- Branded click-and-collect storefronts
- Tenant onboarding and operational tooling
- Staff and admin workflows
- Payments and messaging integrations
- Platform-managed subdomains and custom storefront domains

Core technologies:

- Django
- django-tenants
- PostgreSQL
- HTMX
- Alpine.js
- Tailwind CSS
- Twilio WhatsApp API
- Yoco
- Gunicorn
- Nginx

Website: https://clickcollect.coffee
Documentation: https://docs.clickcollect.coffee

### Naughty Bean Coffee

Naughty Bean Coffee is the brand and commerce side of the ecosystem.

- Coffee brand presence and customer-facing ordering surfaces
- Support and donation flows for product and open-source work
- Real-world testing ground for ordering, branding, payments, and customer experience decisions

Website: https://www.naughtybean.coffee
E-Commerce Store: https://shop.naughtybean.coffee

## What we do

We design and build:

- Multi-tenant SaaS products
- Self-hosted operational platforms
- Security and infrastructure tooling
- Documentation portals and technical content systems
- Branded landing pages and lightweight marketing sites
- Payment, messaging, and workflow integrations

We work with a bias toward:

- Django-first backend systems
- PostgreSQL-backed application workflows
- Server-rendered UI with HTMX and Alpine.js where it keeps complexity down
- Tailwind CSS for fast, consistent interface delivery
- Infrastructure that is understandable and deployable without unnecessary abstraction
- Open-source where it creates leverage and transparency

## Tech stack

Across the products in this workspace, the stack is centered on Django-first backend systems, server-rendered frontend patterns, PostgreSQL-backed workflows, and practical deployment infrastructure.

## How we think

- Ship useful software early, then harden it in production.
- Prefer clear architecture over fashionable architecture.
- Use automation where it reduces operator load, not where it hides reality.
- Build products that can be run, debugged, and owned by the teams using them.
- Keep the interface practical and the implementation defensible.
